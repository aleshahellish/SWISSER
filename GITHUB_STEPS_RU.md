# Обновление и откат

Production разворачивается Vercel из ветки `main`.

## Проверка после изменения

1. Запустить локальные тесты:

   ```bash
   python3 -m py_compile candle_closure.py luxalgo_structure.py api/*.py
   python3 -m unittest discover -s tests -v
   ```

2. После публикации проверить:

   - `/api/health`;
   - `/api/scanner_action_v6` — полный ответ должен быть меньше 100 000
     символов;
   - `/api/snapshot_action_v6?symbol=TAO_USDT`;
   - `python3 scripts/verify_tao_luxalgo_live.py`.

## Откат

Старые копии исходников и ZIP внутри `main` не хранятся: они создавали риск
изменения неактуального файла. Любую версию можно восстановить по коммиту в
истории Git. Ветка `stable-v1` оставлена как дополнительная страховка и не
используется текущим production.

При откате сначала создать отдельную ветку от нужного коммита и проверить её,
а затем осознанно перенести подтверждённое состояние в `main`. Не выполнять
force-push без отдельного решения.
