TAO — тест MEXC, версия 2

Исправление
-----------
MEXC в январе 2026 года перенёс Futures API:
старый домен: contract.mexc.com
новый домен: api.mexc.com

Как запустить
-------------
1. Распакуйте ZIP в НОВУЮ папку.
2. Дважды щёлкните run_tao_test.bat.
3. При успехе появится tao_snapshot.json.
4. При ошибке пришлите весь текст ошибки.

Логины, пароли и API-ключи не используются.
